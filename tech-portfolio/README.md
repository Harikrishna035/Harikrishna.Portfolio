# Harikrishna — Technical Portfolio

A static portfolio site focused on enterprise software, AI systems, and real-estate ventures.

## Run locally

Open `index.html` in a web browser. No build step or dependencies are required.

## Files

- `index.html` — page structure and content
- `styles.css` — responsive technical visual system
- `script.js` — interaction and reveal effects

The original repository files remain unchanged. This site is intentionally isolated in `tech-portfolio/`.
